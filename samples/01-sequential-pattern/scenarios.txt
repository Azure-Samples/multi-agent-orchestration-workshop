# 시나리오: 일반계고 성취기준 기반 탐구 수업·평가 자료 제작 파이프라인
# 에이전트 흐름: curriculum-mapping-agent(성취기준 매핑) -> lesson-design-agent(탐구 수업 설계)
#              -> activity-author-agent(활동지·발문 작성) -> assessment-reviewer-agent(과정중심평가 및 자료 검토)
# 아래 프롬프트 중 하나를 그대로 사용자 메시지로 입력하세요.

[시나리오 1] 통합과학 - 생명 시스템의 정보 흐름 탐구
일반고 1학년 통합과학에서 "생명 시스템의 정보 흐름"을 주제로 100분 블록 탐구 수업을 준비해 주세요. 학생 28명이 4인 1모둠으로 DNA의 유전 정보가 단백질 형질로 이어지는 과정을 모형과 자료를 이용해 설명하도록 하고 싶습니다. 관련 교육과정 성취기준과 평가 요소를 연결하고, 모둠별 탐구 활동지, 핵심 발문, 오개념을 확인하는 형성평가, 근거 기반 설명을 평가하는 과정중심평가 루브릭까지 포함해 주세요. 정확한 성취기준 코드가 불확실하면 임의로 만들지 말고 교사가 확인할 항목으로 표시해 주세요.

[시나리오 2] 국어 - 알고리즘 추천과 미디어 비평 토론
일반고 2학년 국어 수업에서 "알고리즘 추천은 우리의 정보 선택을 넓히는가, 좁히는가"를 주제로 50분 토론 수업을 설계해 주세요. 학생들은 상반된 관점의 글 두 편을 읽고 주장, 근거, 자료의 신뢰성을 분석한 뒤 모둠 토론에 참여합니다. 교육과정 성취기준과 연결한 학습 목표, 읽기 분석표, 토론 역할 카드, 교사용 발문 5개, 토론 후 성찰 문항, 주장과 근거의 타당성을 평가하는 루브릭을 만들어 주세요. 특정 플랫폼이나 학생의 실제 이용 기록은 요구하지 마세요.

[시나리오 3] 수학 - 학교생활 자료를 활용한 통계적 문제 해결
일반고 1학년 수학에서 대푯값과 산포도를 활용하는 100분 프로젝트 수업을 준비해 주세요. 개인정보가 포함되지 않은 가상의 "학생 통학 시간과 수면 시간" 자료를 제공하고, 학생 30명이 3인 1조로 평균·중앙값·범위를 비교해 자료에 적합한 설명을 선택하도록 하고 싶습니다. 관련 성취기준, 단계별 수업안, 가상 데이터가 포함된 활동지, 계산 결과를 해석하는 발문, 수준별 도움 자료, 모둠 산출물과 개인 성찰을 함께 보는 평가 루브릭을 작성해 주세요.
